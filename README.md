# 🚀 Backend Development Learning Repository

A comprehensive repository containing full-fledged backend projects and learning modules built with **Node.js**, **Express.js**, **MongoDB**, and **Modern Authentication & Cloud Storage architectures**. 

Following the backend engineering series by **Ankur Prajapati**.

---

## 📂 Projects Overview

| Directory | Description | Key Technologies |
|---|---|---|
| [Spotify-Clone](./Spotify-Clone) | Full-featured Spotify REST API with Role-Based Access (User & Artist), Multer + ImageKit Cloud Audio Uploads, and Album Management. | `Node.js`, `Express 5`, `MongoDB`, `JWT`, `ImageKit`, `Multer` |
| [jest](./jest) | API Unit & Integration testing suite with Jest & Supertest. | `Jest`, `Supertest`, `Express` |
| [mini-Instagram](./mini-Instagram) | Full-stack mini Instagram clone featuring authentication, post feeds, media handling, and client integration. | `Node.js`, `Express`, `MongoDB`, `React / Client` |
| [Authentication](./Authentication) | Complete JWT-based authentication system with password hashing (`bcryptjs`), protected routes, and HTTP-only cookies. | `Node.js`, `Express`, `JWT`, `Bcrypt` |
| [NotesApp](./NotesApp) | CRUD Notes application with database persistence and RESTful API endpoints. | `Node.js`, `Express`, `MongoDB` |
| [Server-Setup](./Server-Setup) | Foundational Node.js & Express server configuration and middleware setup guide. | `Node.js`, `Express` |

## 🎵 Featured Project: Spotify Backend Clone

For detailed documentation, endpoint specifications, and setup instructions for the Spotify Clone, visit:
👉 **[Spotify-Clone Documentation](./Spotify-Clone/README.md)**

### Highlights:
- 🔐 **Role-Based Authorization (RBAC)**: Distinct permissions for `user` and `artist`.
- 🎧 **Media Upload Pipeline**: Streaming and uploading audio to ImageKit CDN.
- 💿 **Mongoose Relational Schemas**: Seamless populate queries across Users, Music Tracks, and Albums.
- 🍪 **Secure Cookie Sessions**: Stateless JWT verified through HTTP-Only cookies.

## 🛠️ Global Getting Started

To run any of the projects locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/jaikaran109/Backend-AnkurPrajapati.git
   cd Backend-AnkurPrajapati
   ```
2. Navigate to your desired project directory:
   ```bash
   cd Spotify-Clone
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up your `.env` file (refer to each project's `.env.example` or README).
5. Start development server:
   ```bash
   npm run dev
   ```
